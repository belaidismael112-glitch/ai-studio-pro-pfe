# AI Studio Pro — Brand Kit

This folder contains ready-to-use visuals for your PFE report, slides, and demo.

## Included

- `assets/logo.png` — square logo (1024×1024)
- `assets/icon_256.png` — app icon (256×256)
- `assets/banner.png` — header/banner image
- `assets/architecture.png` — high-level system architecture diagram
- `assets/screenshots/*.png` — UI mock screenshots (for documentation)

## Notes

- The banner + logo are PNG for compatibility with Word/PDF/PowerPoint.
- For a real production release, consider vector (SVG) export and code-signed desktop installers.
